# Release gate assessment

Assessed 2026-10-30 against the gates in the [roadmap](roadmap.md) for the release candidate `v0.1.0-rc.2`; reassessed 2026-11-07 for the content of `v0.1.0`, which equals `v0.1.0-rc.3` (KB-027). The patch release `v0.1.1` changes only the init engine and the init commands and skills, which run only when the user invokes them; the always-loaded context is unchanged (1253 tokens estimated, [context overhead](context-overhead.md)), so the measurements below carry over without a new behavior run. Unmeasured items are labeled unassessed, not passed. The behavior work is a pilot plus later experiments, not statistical proof.

| Gate | Status | Evidence and limits |
| --- | --- | --- |
| No critical requirement, security, or boundary violation | Met for the pilot tasks; not assessed beyond them | The three pilot reports ([first](../tests/behavior/pilot-results-2026-10-29.md), [retest](../tests/behavior/pilot-retest-results-2026-10-29.md), [follow-up](../tests/behavior/pilot-followup-results-2026-10-29.md)) record none identified in manual review. Later experiments did not review diffs for such violations; the blind diff judge was not reliable enough to use ([calibration](../tests/behavior/kb216-calibration-2026-10-30.md)) and is biased against toolkit arms (KB-234). |

On the release content: idle-gap 10/10 against 8/10 ([KB-027](../tests/behavior/kb027-small-overhead-2026-11-07.md)), not significant. `/kaboost:plan` passed 10/10 against 7/10 on idle-gap, not significant (p = 0.21). ## Conclusion

The release content meets the stated non-inferiority gates where they were measured, including the Small-task overhead gate, with the gaps above labeled. It does not demonstrate better outcomes and makes no such claim. Under [ADR 012](decisions/012-stable-release-gates.md) the stable `v0.1.0` no longer waits for the real-use evidence of KB-025, which continues for 0.2.
